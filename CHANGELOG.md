# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-15

### Added
- **Editorial Experience:** Complete redesign of the user interface into a premium, cinematic editorial layout.
- **Cinematic Wall Cards:** Implemented a luxury magazine-style storytelling section with high-fidelity typography (Playfair Display & Inter).
- **Nostalgic Gallery:** Restored the 12-card "Mix" floating Polaroid gallery with authentic personal assets and thematic descriptions.
- **Backend Hardening:** Integrated a robust Application Factory pattern and asynchronous email delivery system for the "GIFT" feature.
- **High-Contrast Navigation:** Added fixed "LOG OUT" and premium "GIFT" call-to-action buttons for improved accessibility.
- **Entrance Animation:** Cinematic post-login loading screen with a 3-second progress sequence.
- **Asset Integration:** Synchronized high-quality personal photography and portraits across all thematic sections.

### Fixed
- Resolved broken email trigger logic on the Gift button using modern Fetch API.
- Fixed layout overlaps and visibility issues for navigation links.
- Corrected gallery caption mappings to match the nostalgic Phase-1 original intent.
